# Third-party material

The folder mithril/ is the Mithril example from TodoMVC, https://github.com/tastejs/todomvc at commit
ff43b02e59dfa604386bb382034b2cd07c2bcd8a. The licence of TodoMVC is in LICENSE-todomvc.md (MIT, copyright Addy
Osmani, Sindre Sorhus, Pascal Hartig, Stephen Sawchuk). Inside it:

- mithril/node_modules/mithril/mithril.js: Mithril 0.2, MIT licence, https://mithril.js.org/
- mithril/node_modules/todomvc-common/: todomvc-common, MIT licence.
- mithril/node_modules/todomvc-app-css/index.css: todomvc-app-css by Sindre Sorhus, licensed CC BY 4.0
  (https://creativecommons.org/licenses/by/4.0/). Changes made by the coding agent in this repo: none, this file is
  byte for byte the upstream one.
- mithril/js/ and mithril/index.html: the example's own code (Taylor Hakes and Jean-Philippe Monette, see the footer
  of index.html). Changes made by the coding agent in this repo, and only these: mithril/js/controllers/todo.js and
  mithril/js/views/main-view.js (see the commit "T-1: app change that Kane passed").

The checks in check/ are ours (MIT).
